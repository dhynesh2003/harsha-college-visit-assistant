1. Create a Supabase project.
2. Open Supabase SQL Editor.
3. Run supabase-schema.sql.
4. Open assets/config.js.
5. Paste:
   - Project URL
   - Publishable key or legacy anon key
   Never use service_role in this browser app.
6. In Supabase Authentication, enable Email/Password.
7. Deploy the COMPLETE folder to Netlify.
8. Open the site and create/sign in to Harsha's account.
9. On phone, install the deployed site from browser:
   Android Chrome -> Install app / Add to Home Screen
   iPhone Safari -> Share -> Add to Home Screen

The same Supabase account will see the same data on laptop and phone.
JSON export remains available as a separate backup.
